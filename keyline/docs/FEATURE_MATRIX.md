| Feature | Current status | Hosted/backend requirement |
|---|---|---|
| Existing Keyline training desk, converter, reference, keying tools, backup | Retained in current source | Static hosting only |
| Progressive listening course | Prototype included | Static; curriculum/checkpoint refinement needed |
| Mistake-weighted listening | Prototype included | Static; unify stats across all modules |
| Custom lesson and daily drills | Prototype included | Static |
| Scripted QSO scenarios | Prototype included | Static; full state machine still needed |
| Full CW Racer sending/race mechanics | Partial/existing overlap | Static; implement/validate timing and scoring |
| Full Flappy/Battleship/invaders game mechanics | Partial | Static |
| ON AIR live keying relay | Not live | Realtime backend + authorization/abuse controls |
| Global Chat, Auto CW, Hide Text | Not live | Realtime backend + moderation/rate limits |
| CW Duel lobby/matchmaking | Not live | Realtime backend + server-authoritative match state |
| Weekly leaderboard/community totals | Not live | Shared database + abuse/anti-cheat policy |
| Local AI QSO interpreter | Not included | Browser inference runtime + model download |
| Automatic cross-device sync | Not included | Optional authenticated backend, consent and conflict handling |
| PWA install/offline shell | Added | GitHub Pages HTTPS; first online visit to cache |
| Standalone HTML | Included | No hosting needed |
